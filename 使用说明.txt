研伴公开版

每位使用者填写自己的 DeepSeek API Key，费用由自己的 DeepSeek 账户承担。
Key 默认仅在当前页面内存。可勾选“在此浏览器记住 API Key”并保存，以明文写入当前浏览器 localStorage，刷新或重新打开后自动恢复；仅建议在自己的设备使用。不上传本站服务器。取消勾选并保存将删除本地副本、保留本页使用；点击“清除 Key（含本机保存）”将同时清除内存及本地副本。清除浏览器站点数据也会删除已记住的 Key。
PDF 和笔记仅保存在当前浏览器的本地存储，不上传网站服务器。主动翻译、问答和生成读书卡时，必要文字会从浏览器直接发送给 DeepSeek 官方。
同一电脑/同一浏览器资料可能被其他共用者访问，请勿在不信任的共用设备导入私人论文。清除站点数据会删除本地论文和笔记，重要笔记请导出备份。

流程：打开网页 → 模型设置填写自己的 Key → 导入 PDF → 按页阅读、选段翻译、提问 → 读书卡中 AI 填写空白栏目。
全文读书卡分段读取所有已提取文字后汇总，显示页数和段落覆盖；缺文字页面会提示。覆盖不等于模型理解完全正确。
公开版采用 PDF.js 基础文本提取，不等同于本地 Docling。多栏阅读顺序、图表、公式请对照原 PDF；暂不支持扫描件 OCR。
回答支持标题、加粗、列表、引用、代码和表格，原文编号可点击定位。模型输出的 HTML 不执行。
支持 20 MB / 100 页 PDF。全文读书卡最多约 51 万字符，超出时明确报错，不隐蔽截断。
浏览器必须支持现代 JavaScript、IndexedDB、Web Worker，并能访问 DeepSeek API；若网络或浏览器跨域策略阻止直连，需要换可访问的网络或使用本地版。

开发与部署
- site-bundle.zip 是审核过的纯静态网站文件；不含密钥、用户 PDF 或本地后端数据。
- 依赖 PDF.js 6.4.299，发行包完整性已校验，许可证随 vendor/pdfjs/LICENSE 提供。
- 将 site-bundle.zip 解压到 dist，使用 HTTPS 静态托管；.mjs 必须以 JavaScript MIME 类型提供。
- 本机预览：python preview.py，然后打开 http://127.0.0.1:4318 。该地址只供本机，公网使用需要实际部署。
- 协议回归检查：node test-research.mjs 。模型响应使用测试替身，不产生收费调用。
