研伴 public-0.6 · 论文阅读与云端研究空间
网址：https://minestab.github.io/yanban-research-assistant/

开始使用
1. 直接打开网页即可本机阅读。需要跨电脑同步时，点左下角“登录 · 同步研究空间”，选择“使用 GitHub 登录 / 注册”。首次登录自动创建研伴账号，只请求邮箱读取权限，不读取代码仓库。
2. 如果以前已在这个浏览器导入论文，登录后点“导入本机未登录资料”，再点“立即同步”。旧论文不会自动消失或删除；未登录空间和账号空间分别保存。
3. 在“模型设置”填写自己的 DeepSeek API Key，选择模型并保存。Key 默认仅在本页内存；可勾选在此浏览器记住，以明文保存在浏览器 localStorage。Key 直接发送到 DeepSeek，不上传论文同步云端。模型费用由自己的 DeepSeek 账号承担。
4. 点击“导入论文”，选择含文字层的 PDF（最大 20 MB、100 页）。PDF 在浏览器内解析；未登录时只保存本机。

读论文与公式
- 默认显示 PDF 原貌：按原始页面绘制公式、上下标、表格和图片，并叠加可选择的文字层。
- 鼠标划选一部分正文，右侧自动切到翻译页；点击翻译选中语段。原文视图也支持跨段连续选文。只有主动点击翻译才会调用模型。
- 若选区因复杂排版无法对应原文，会提示重新选择。文本提取和文字层不等于公式 OCR，扫描件暂不支持 OCR。
- “双语对照”显示已经翻译的整段；片段翻译在右侧查看。
- “公式原貌”可单独放大查看当前 PDF 页。
- 模型回答和笔记预览支持 Markdown、表格及 LaTeX 数学公式：行内 $x_i$ 或 \(x_i\)，独立公式 $$...$$ 或 \[...\]。格式错误的公式会保留原式，不执行模型 HTML。

笔记与分类
- 右侧“笔记”或左栏“研究笔记”：每篇论文有独立笔记，输入自动保存在本机。可以引用当前选文、预览公式排版、导出 Markdown。
- “读书卡”用于研究问题、方法、证据、局限、待追问的问题等结构化整理；AI 只填写空白栏目，不覆盖已有笔记。
- “我的论文”左侧＋可新建文件夹；每篇论文右侧的分类下拉框用于移动。可搜索标题/文件名、排序、重命名、移除文件夹。移除文件夹保留论文，归到“未分类”。

跨电脑同步
- 每次结束编辑后点击“云同步 → 立即同步”。新设备使用同一个 GitHub 账号登录，再点击“立即同步”。当前版本为手动同步。
- 同步内容：PDF 原文件、解析文字、文件夹和归类、自由笔记、读书卡、摘录。
- 不同步：DeepSeek API Key、临时对话记录、临时翻译结果、当前页码。
- 每人只有自己的私有空间。论文桶不是公开下载目录；网页公开不代表论文公开。
- 两端分别编辑不同内容时自动合并；同时改动相同内容时会提示冲突，可下载两份备份，再选择本机或云端冲突项。发生冲突时不会静默覆盖笔记。
- 同一账号在同一个浏览器来源下只允许一个编辑标签页。关闭原标签页后可刷新另一个标签页继续。
- 登录后仍会缓存资料在本机。共用电脑不要导入私人资料；退出账号并清除该站点数据，才能清除本机缓存和记住的 Key。重要笔记建议定期导出。
- GitHub 登录是当前公开入口。普通访客邮箱注册尚未开放，须另配邮件发送服务后启用；不需要注册 Supabase 管理账号。

模型与结果
翻译、问答和全文读书卡会发送必要文字给 DeepSeek，并使用你的账户额度。问答先检索论文再生成和复核，提供可定位段落引用。全文读书卡读取所有已提取文字，最多约 51 万字符，显示覆盖页数和缺失提示。模型仍可能出错，引用存在不等于论断正确；请对照 PDF。

开发维护
- site-bundle.zip 是完整静态网页构建，含可公开的 Supabase 项目 URL 和 publishable key，不含数据库密码、OAuth client secret、用户 Key、用户 PDF 或登录令牌。
- 数据权限在 Supabase RLS 和私有存储策略中执行，不能仅依赖前端隐藏。
- supabase-setup.sql 提供数据表、保存函数与权限配置，当前项目已执行。不要把管理员 service_role/secret key 填到 cloud-config.js。
- 依赖 PDF.js 6.4.299、KaTeX 0.19.0、Supabase JS 2.118.0，发行包 SHA-512 已校验，许可证附在 vendor。
- node test-research.mjs：运行 22 项既有协议测试及 8 项新增选文/同步状态测试，使用模型替身，不产生模型费。
- python preview.py：本机预览 http://127.0.0.1:4318/ 。需要现代浏览器、IndexedDB、Web Worker，并能访问 GitHub、Supabase 和 DeepSeek。
- 公网部署使用 HTTPS 静态托管，.mjs 必须作为 JavaScript 提供。更换域名时同步修改 Supabase 的 Site URL / Redirect URLs。
